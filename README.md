# SmartSpend

SmartSpend is a student-first, privacy-first personal finance web application for Indian college students and early-career users.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript (Strict Mode)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Backend (Phase 3+):** Supabase (Auth & PostgreSQL RLS)

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run local development server:**
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
